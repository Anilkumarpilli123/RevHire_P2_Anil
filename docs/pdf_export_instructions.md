# Generating PDF Documents

To convert the Markdown documentation (with Mermaid diagrams) into PDF formats easily, you can use the **VS Code Workspace** extensions:

## Method: Using Markdown PDF in VS Code
1. Open Visual Studio Code.
2. Go to the Extensions view (`Ctrl+Shift+X`).
3. Search for and install **"Markdown PDF"** by *yzane*.
4. Open any of the `.md` documentation files in the `docs/` folder (e.g., `er_diagram.md`).
5. Right-click inside the file editor and select **"Markdown PDF: Export (pdf)"**. 
6. Alternatively, press `Ctrl+Shift+P` (Command Palette), type `Markdown PDF: Export (pdf)` and hit Enter.

It will immediately generate `.pdf` versions of the documents directly alongside the Markdown files.
